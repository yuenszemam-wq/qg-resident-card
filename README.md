# Queen's Garden 限定居民卡製作

選相片、填名字、IG 和日期，就可以下載限定居民卡的 PNG 圖片或 5 秒 MP4 影片。整個網頁只有 `index.html` 一個檔案，素材圖已經內嵌在檔案裏面。

## 部署（Cloudflare Pages）

- Framework preset：None
- Build command：留空
- Build output directory：`/`

## 更新

在 GitHub 把 `index.html` 換成新版本，Cloudflare 會自動重新部署。

## 備註

- 「限定居民」和「Queen's Garden」用的是 Canva 原圖。
- 名字用 Google Fonts 的 Chiron GoRound TC（代替 Canva 的「可畫飄逸隸」）。
- IG 和日期用 Google Fonts 的 Mali 斜體（代替「可畫影流體」）。
- 影片用瀏覽器內建錄影功能即時錄製：iPhone Safari 會輸出 MP4，部分瀏覽器只能輸出 WebM。
