# 字體（本地 WOFF2）

IG 和日期可在「文字微調」揀以下字體（預設 Kalam）。全部取自 Google Fonts、未經修改，授權都是 SIL Open Font License 1.1，授權全文及版權聲明見同名 `OFL-*.txt`。瀏覽器只會下載實際用到的字體。

| Mali | `mali-500/700-latin.woff2` | 500、700 | `OFL-Mali.txt` |
| Itim | `itim-400-latin.woff2` | 400 | `OFL-Itim.txt` |

角色名字可揀的字體（Zen Kurenaido、Yuji Syuku、Yuji Boku、Yusei Magic、Mochiy Pop One、Kiwi Maru、Darumadrop One、Hachi Maru Pop、Chiron GoRound TC）都是 SIL OFL 1.1。因為中日文字體檔太大，經 Google Fonts 按字分片、選用時才載入，不放在本 repo。
